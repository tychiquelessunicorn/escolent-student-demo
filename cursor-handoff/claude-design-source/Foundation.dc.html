Escolent · Visual Foundation · Phase 2 refresh

Warmer, rounder, still calm

The original pass read trustworthy but closer to an adult SaaS dashboard than something made for a 13–14 year old. Three changes here, nothing else touched: a warmer neutral base, a second accent reserved for genuine achievement moments, rounder shapes throughout, and a lighter touch on type weight and scale. No streaks, points, or badge mechanics — and no illustration yet, that's a separate decision.

1. Color
Warmer neutral base. New achievement accent, used sparingly. Blue stays the one interactive color.
2. Shape
Radius scale pushed up across the board — 22px on cards, 26px on modals, 14px on buttons and inputs.
3. Type
Same pairing. Crimson Pro moved up to 700 and a larger scale for headlines; uppercase labels lost their corporate edge.

Type scale

Kept Crimson Pro + Geist — the pairing itself isn't the problem. What read adult was Crimson Pro sitting at a light-ish 600 weight and a modest scale, next to Geist uppercase labels at 700 weight with wide letter-spacing (a very admin-dashboard habit). Crimson Pro now sits at 700 and a size step up wherever it carries a headline, and the uppercase labels dropped to 600 weight with tighter spacing. If this still doesn't land, the honest next lever isn't weight — it's swapping Crimson Pro for a rounder, less editorial serif (or one warm rounded sans doing everything). Flagging it rather than making that call here.
